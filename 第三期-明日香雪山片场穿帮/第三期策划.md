# 第三期策划：明日香雪山片场穿帮

## 一句话概念

前半段像一支认真拍的末世机甲短片，后半段突然变成 `人工智障派遣所` 片场翻车现场。

## 最核心的反转

观众一开始看到的是：

- 大雪山
- 明日香
- 二号机
- 驾驶舱
- 情绪拉满的重场戏

观众后来才发现：

- 雪山是泡沫景片
- 风雪是鼓风机 / 吹风机吹出来的
- 二号机是纸壳和脚手架搭的假模型
- 片场工作人员全是派遣所的小黄人
- 他们举着 `没有 token 了` 的牌子，慌忙收工

## 片子调性

前半段：

- 冷
- 空
- 大
- 严肃
- 有情绪

后半段：

- 荒诞
- 片场穿帮
- 收工混乱
- 一本正经地没预算
- 派遣所式人工智障

## 推荐时长

- `15-18 秒` 最稳

不建议太长。这个片子的笑点靠反转，不靠完整叙事。

## 推荐结构

### 镜头 1

雪山大全景。

风很大，环境很冷，远处隐约能看到二号机轮廓。

作用：

- 先把观众骗进“这是一支正经短片”

### 镜头 2

从她肩后拍过去。

动作不要太多，重点是：

- 半身或上半背身
- 观众开始跟着她的视线往前看
- 远处机体仍然巨大
- 还是严肃正片感

### 镜头 3

明日香停下，侧脸缓缓抬头。

这一镜只拍她的反应：

- 风雪里的侧脸
- 缓慢抬头
- 看向画外上方
- 不拍机体本身

### 镜头 4

插入栓 / 驾驶舱舱门细节。

只拍：

- 她的手
- 红色冬装袖口
- 冰冷的舱门结构

这是反转前最后一张严肃镜头。

### 镜头 5

突然有人在画外大喊：

`咔！`

气氛瞬间断掉。

同一镜头或紧接下一镜，雪山片场穿帮：

- 泡沫雪块
- 吹风机 / 鼓风机
- 纸壳二号机结构
- 景片边缘露出来

### 镜头 6

小黄人片场工作人员冲出来收工。

要点：

- 有的举 `没有 token 了`
- 有的在拆景
- 有的拖着纸壳板
- 有的慌张关风机
- 有的把雪泡沫往袋子里扒拉
- 明日香不要消失
- 她应该退到远处小景，站在背景里叉着腰生气
- 或者有一点跺脚、气得不行但没人理她
- 前景是忙乱撤场，后景是她一个人认真生气

这一镜同时也承担结尾收口。

可以保留：

- `没有 token 了`
- `先收工`

这种牌子或片场信息，不一定还要单独再切一镜。

## 这支片子的成功标准

不是“特效像不像大片”，而是：

1. 前半段能不能先把人骗进去
2. `咔` 那一下是不是够突然
3. 反转后片场细节是不是够好笑
4. 小黄人收工是不是够忙乱、够穷、够派遣所
5. 明日香在后景里生气这件事是不是够好笑、够清楚

## 视觉设计建议

### 前半段

- 冷蓝灰
- 大风雪
- 空镜头
- 机甲压迫感

### 后半段

- 灯光稍微回暖
- 曝露出片场真实材质
- 泡沫 / 纸壳 / 胶带 / 支架
- 小黄人冲进来后，气氛从史诗掉回手工作坊

## 风险点

### 1. IP 风险

对外发布时，标题最好不要直接把完整 IP 名写太满。

可用更稳的说法：

- `雪山机甲片场穿帮`
- `某经典女驾驶员在雪山找机体，结果片场没 token 了`

### 2. 模型容易把前后风格做断

所以这支片子最好从一开始就按：

- 前半段严肃镜头
- 后半段片场镜头

分开生成，再在后期拼。

### 3. 反转点不能太早

前半段至少要给观众 `4-6 秒` 的认真感，不然笑点立不住。

## 当前建议

下一步直接做：

1. `镜头 1-4` 严肃雪山段的静帧或视频 prompt
2. `镜头 5-6` 片场穿帮段的静帧或视频 prompt
3. 再决定是不是继续走可灵 / Omni / 图生视频路线

## 推荐生成拆分

如果可灵一条 `15 秒` 不够稳，建议拆成两段：

1. `第一段`
   - 镜头 1 到镜头 3
   - 雪山建立、肩后跟进、抬头反应
2. `第二段`
   - 镜头 4 到镜头 6
   - 手握舱门、咔、穿帮收工

## 后半段补充表演要求

穿帮以后，真正的喜剧关系应该是：

- 前景：小黄人们忙着撤场、拆景、拖线、扛灯、举牌
- 后景：明日香本人还沉浸在刚才那场严肃戏里，叉着腰生气，或者在雪地里跺脚

她不要也变成夸张喜剧演员。

她越认真、越被晾在后面，前景的小黄人越一本正经地收工，这个反差就越好笑。
