# 第三期-明日香雪山片场穿帮

## 主题

`明日香在雪山寻找二号机，结果整个末日场景其实是派遣所片场`

## 当前目标

- 做一支 `15-20 秒` 的剧情反转短片
- 前半段先让观众以为是严肃、末世、情绪化的大场面
- 后半段突然喊 `咔`
- 揭示：
  - 雪山是泡沫和鼓风机吹出来的
  - 二号机是纸壳模型
  - 片场工作人员全是派遣所的小黄人
  - 因为 `没有 token 了`，整个片场被迫收工

## 当前工作流

1. 先锁剧情结构和分镜
2. 再决定每一镜是静帧、图生视频，还是直接视频生成
3. 最后统一做收尾旁白和片场杂音

## 目录说明

- `原图/`：后续参考图、角色参考、片场元素参考
- `提示词/`：视频 prompt、静帧 prompt、分镜提示
- `生成结果/`：视频候选、静帧候选、音频候选
- `发布素材/`：小红书标题、正文、首评、封面说明
