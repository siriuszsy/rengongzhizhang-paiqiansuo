# 第三期可灵执行单

目标：

- 尽量少手动
- 不做连续融图
- 让镜头按静帧切换，而不是强行连贯变形

## 总体建议

这期不要用：

- 双图强过渡
- 从严肃雪山硬 morph 到片场收工

这类转场很容易崩。

更稳的方式是：

- `自定义分镜`
- `每格一张图`
- 按图片切镜头
- 靠声音和节奏把片子串起来

## 推荐分镜数

- `6 个分镜`
- 总时长：`15 秒`

## 推荐时长分配

1. 镜头1：`2.4秒`
2. 镜头2：`2.2秒`
3. 镜头3：`2.2秒`
4. 镜头4：`2.0秒`
5. 镜头5：`2.4秒`
6. 镜头6：`3.8秒`

合计：

- `15.0 秒`

## 上传顺序

如果你已经有静帧，建议按这个顺序上传：

1. 雪山大全景
2. 肩后跟进
3. 侧脸抬头
4. 手握插入栓舱门
5. 片场穿帮
6. 小黄人收工 / 收尾

如果没有全部静帧，也至少先保证有：

- 镜头3
- 镜头4
- 镜头5
- 镜头6

## 全局画面 Prompt

```text
请基于我上传的分镜图片，生成一条15秒、9:16、高质量三维动画剧情反转短片。不要把镜头之间做成连续变形过渡，而是按图片做清晰的电影式切镜头。每个分镜都保持原图的构图、角色关系和场景气质，只做轻微的镜头推进、角色小动作、局部环境动态。

前半段必须像认真拍的冷峻机甲雪山短片：冷、空、严肃、末世、情绪重。
后半段必须突然掉到低成本片场穿帮喜剧：泡沫雪、吹风机、纸壳机甲、小黄人收工、没有 token 了。

整体要像高质量动画短片，而不是PPT，也不要做成连续融图特效。
```

## 全局音频 Prompt

```text
整条片子的音频要有明显的前后反差。

前半段：
- 冷峻、空旷、压抑的电影感配乐
- 风雪声
- 远处金属和冰雪环境音
- 没有人说话

反转点：
- 突然一声画外“咔！”
- 气氛瞬间断掉

后半段：
- 片场忙乱环境音
- 鼓风机、吹风机、泡沫摩擦声、纸壳拖动声、工具碰撞声
- 小黄人含混不清的忙乱 chatter
- 不要大量清晰对白

结尾如果需要一句旁白，可以用：
“没有 token 了，先收工。”
或者：
“人工智障派遣所，先收工。”
语气要像一本正经的荒诞片场广播。
```

## 六个分镜怎么填

### 分镜1：雪山大全景

- 时长：`2.4秒`

```text
保持大雪山大全景和严肃机甲片气质。风雪强，远处巨大的红色机甲半埋在雪中，红发女驾驶员在前景或中景艰难靠近。镜头只做轻微推进，像末世机甲电影开场。
```

### 分镜2：肩后跟进

- 时长：`2.2秒`

```text
保持第一镜的雪山和机体连续性，但镜头推进到她肩后或半身背后。观众越过她看向前方埋雪的红色机体。风雪很强，气氛仍然严肃，没有任何喜剧感。
```

### 分镜3：侧脸抬头

- 时长：`2.2秒`

```text
这一镜只拍她的反应。保持右向侧脸或近侧脸，冬装和双束头发不变。她停下，缓缓抬头，看向画外上方。不要出现机体，不要穿帮，重点是压住情绪。
```

### 分镜4：手握插入栓舱门

- 时长：`2.0秒`

```text
严肃的近景插入镜头。只拍红色冬装袖口、真实的人手、冰冷的机体舱门或插入栓舱门结构。手已经握住舱门，下一秒就要打开。不要出现喜剧，不要穿帮。
```

### 分镜5：喊咔，片场穿帮

- 时长：`2.4秒`

```text
同一个雪山机甲场景突然暴露出低成本片场真相。泡沫雪、吹风机、纸壳机甲、支架、胶带、景片边缘一下子露出来。镜头不要做复杂转形，只要把严肃气氛突然打断，像有人刚喊了“咔”。
```

### 分镜6：小黄人收工 / 收尾

- 时长：`3.8秒`

```text
黄色小电脑员工像片场工作人员一样冲进来收工。有人举“没有 token 了”的牌子，有人关风机，有人拖纸壳景片，有人把泡沫雪往袋子里装，有人扛灯，有人拖电线。场面要很忙、很穷、很可爱，像一支认真但预算耗尽的荒诞剧组。红发女演员不要消失，她应该在远处后景里小小地叉着腰生气，或者跺脚，像是唯一一个还把这场戏当真的人。这一镜直接承担收尾，不再单独切第七镜。
```

## 最稳的工作流

### 如果要拆成两段

建议这样拆：

1. `第一段`
   - 分镜1 到 分镜3
   - 雪山建立、肩后跟进、抬头反应
2. `第二段`
   - 分镜4 到 分镜6
   - 手握舱门、咔、穿帮收工

### 第一轮

- 先不开复杂旁白
- 先确认画面顺不顺
- 只要：
  - 风雪环境音
  - `咔`
  - 小黄人收工杂音

### 第二轮

如果第一轮画面顺，再决定要不要补一句收尾：

- `没有 token 了，先收工。`
- 或 `人工智障派遣所，先收工。`

## 这一期最重要的不是特效

而是三件事：

1. 前半段能不能把人骗进去
2. `咔` 那一下够不够突然
3. 后半段片场是不是穷得好笑、忙得很真

只要这三件事成立，这期就能发。
