# 人工智障派遣所

一个公开记录 AI 内容实验、提示词、素材和小项目的仓库。

简称：`派遣所`

当前方向：

- 小红书内容实验
- 文生图 / 图生图测试
- vibe coding 小工具
- 真实模拟与翻车记录

## 仓库结构

- `第一期-五张普通的照片能不能生成真广告/`：AI 假广告实验，已整理出小红书最终版
- `第二期-火影女忍者西安一日游/`：AI 二次元城市旅拍 / 壁纸特辑，已整理出小红书最终版
- `素材池/`：通用原始素材、截图、参考图
- `模板/`：复用模板，包括单期策划、发布文案、实验记录
- `阶段总结-2026-04-26.md`：当前阶段策略、运营结论和发布建议

## 约定

1. 一个内容主题一个文件夹。
2. 每一期至少保留原图、提示词、生成结果、发布素材。
3. 发布前尽量保留翻车图，不只保留最好看的结果。
4. 能公开的过程尽量公开，方便后续复盘和复用。
