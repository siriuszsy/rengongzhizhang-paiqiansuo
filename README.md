# 人工智障派遣所

一个公开记录 AI 内容实验、提示词、素材和小项目的仓库。

简称：`派遣所`

当前方向：

- 小红书内容实验
- 文生图 / 图生图测试
- vibe coding 小工具
- 真实模拟与翻车记录

- `第六期-待定视频企划/`：预留给下一期视频内容，占位中
- `第七期-抽风版贪吃蛇/`：vibe coding / AI 验货特别篇，已顺延并保留完整策划

## 约定

1. 一个内容主题一个文件夹。
2. 每一期至少保留原图、提示词、生成结果、发布素材。
3. 发布前尽量保留翻车图，不只保留最好看的结果。
4. 能公开的过程尽量公开，方便后续复盘和复用。
