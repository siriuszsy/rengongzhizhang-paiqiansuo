`五张普通的照片能不能生成真广告`

`让人工智障上班第 1 期`

## 这一期要验证什么

验证 `GPT Image 2` 是否已经强到可以把普通素材直接拉到接近“真广告图”的水平。

重点不是评测模型参数。

重点是看：

1. 普通人会不会觉得“像真的”
2. 哪类题材最容易成功
3. 哪类题材最容易翻车

## 五个题材

### 1. 单人照 -> 高级品牌广告

目标：

把普通人像改造成 `高端香水 / 杂志封面 / 轻奢 campaign`

期待结果：

- 画面高级
- 人脸保留度高
- 构图像真海报
- 有少量精致文字也可以，但不要强依赖模型生成复杂文案

保留结果：

- 最像真品牌的一张
- 最翻车的一张

### 2. 宠物照 -> 奢侈品 / 电影海报

目标：

把普通宠物图改造成 `奢侈品广告` 或 `电影海报主视觉`

期待结果：

- 宠物主体明确
- 表情可爱但不低幼
- 背景和灯光有品牌感

保留结果：

- 最有“广告感”的一张
- 最离谱的一张

### 3. 纯文生图：不存在的 App 海报

概念：

`i 人拒绝饭局助手`

一句话介绍：

帮社恐和 i 人生成“礼貌但不尴尬”的拒绝回复。

目标：

生成像真的 `App 发布海报 / 宣发 KV / App Store 截图页`

### 4. 纯文生图：不存在的离谱品牌

概念：

`打工人情绪急救包`

一句话介绍：

一个专门给上班人“续命”的虚构品牌。

目标：

生成像真的 `消费品广告海报 / 电商主图 / campaign 视觉`

### 5. 纯文生图：更有评论区讨论感的实验概念

概念：

`周一续命喷雾`

一句话介绍：

一瓶献给周一早上的虚构产品。

目标：

做出一张“离谱但又像真品牌”的广告图。

## 正文文案方向

正文不要写成教程。

正文只说 4 件事：

1. 我拿什么做实验
2. 规则是什么
3. 哪个最像真的
4. 哪个最离谱

建议文案结构：

`这次我拿 2 张普通照片和 3 个离谱脑洞，试了下 GPT Image 2。`

`我更关心的不是“它会不会画”，而是“它做出来到底像不像真广告”。`

`结果最像真的，是 ____。最翻车的，是 ____。`

`你们要是有更离谱的题，我下一期继续让人工智障上班。`
